# Security reporting

Use [Aguasto’s vulnerability reporting instructions](https://www.aguasto.com/security) to report a suspected vulnerability. For an account or service issue, use [Aguasto support](https://www.aguasto.com/support).

Include the affected repository, package, or public route, the version if known, the approximate UTC time, and the observed impact. Remove credentials, personal information, and customer data. Ask for a secure way to share sensitive details.

Keep suspected vulnerabilities out of public issues, discussions, and pull requests while Aguasto reviews the report.
