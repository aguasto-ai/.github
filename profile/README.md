# Aguasto

Aguasto is developing AI compute infrastructure for training and inference. Explore GPU systems, plan capacity for your workload, and use our public research tools to compare configurations and assumptions.

| Resource | What you’ll find |
| --- | --- |
| [Aguasto website](https://www.aguasto.com/) | Company information and infrastructure research |
| [GPU catalogue](https://www.aguasto.com/gpus) | Hardware specifications, comparison tools, and availability guidance |
| [Aguasto Console](https://console.aguasto.com/gpus) | Request GPU capacity and follow the review in your workspace |
| [Documentation](https://docs.aguasto.com/) | Console, API, and developer guides |
| [Developer portal](https://www.aguasto.com/developers) | Public APIs, MCP, SDKs, and example integrations |
| [SDKs, CLI, and agent skills](https://github.com/Altssdata/aguasto-agents) | Published clients for the Aguasto public research tools |
| [Trust Center](https://www.aguasto.com/trust) | Terms, privacy, data processing, and service policies |

An early-access capacity request is free and nonbinding. Aguasto confirms availability, placement, and pricing for the requested configuration before a commercial order.
